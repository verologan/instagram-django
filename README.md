# 📸 Instagram Clone — Django

Aplicación web inspirada en Instagram desarrollada con **Python y Django**.

## 🚀 Tecnologías

- Python 3.12
- Django 6.1
- SQLite
- HTML5 / CSS3
- Django Templates
- Git & GitHub

## ✨ Funcionalidades

- 👤 Registro y autenticación de usuarios
- 👥 Perfiles de usuario
- 📸 Publicación de contenido
- ❤️ Sistema de seguimiento
- 🔔 Notificaciones
- ✏️ Edición de perfiles
- 🛠️ Panel de administración de Django

## 📁 Estructura del proyecto

```text
instagram/
├── instagram/
├── profiles/
├── posts/
├── notifications/
├── templates/
├── manage.py
├── requirements.txt
└── .gitignore
```

## ⚙️ Instalación

```bash
git clone https://github.com/verologan/instagram-django.git
cd instagram-django
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Abrir en el navegador: **http://127.0.0.1:8000/**
